{%- comment -%} Nodo WebPage de cada página: tipo según la página, enlace al WebSite, a la organización, a las migas y a la imagen social. CollectionPage + ItemList en los hubs (`coleccion:` o el blog), ContactPage en contacto, AboutPage en nosotros (o `webPageType` en el front matter). `speakable` donde se pinta #en-resumen (`page.resumen`). Usa `_og_image` calculada en head.html. {%- endcomment -%} {%- assign _wp_tipo = page.webPageType -%} {%- unless _wp_tipo -%} {%- if page.coleccion or page.url == "/blog/" -%}{%- assign _wp_tipo = "CollectionPage" -%} {%- elsif page.url == "/contacto/" -%}{%- assign _wp_tipo = "ContactPage" -%} {%- elsif page.url contains "/nosotros/" -%}{%- assign _wp_tipo = "AboutPage" -%} {%- else -%}{%- assign _wp_tipo = "WebPage" -%}{%- endif -%} {%- endunless -%} {%- if page.coleccion -%}{%- assign _wp_items = site[page.coleccion] | sort: "orden" -%} {%- elsif page.url == "/blog/" -%}{%- assign _wp_items = site.posts -%} {%- else -%}{%- assign _wp_items = nil -%}{%- endif -%}
